# Carousel maker: rules

Saved 2026-10-10 from six Do/Don't reference images Sheetal shared. These apply to every
@blok.capital carousel and override older carousel guidance where they conflict
(including the "sticker" style's busy doodles and the 1080x1350 size).

| # | Don't | Do |
|---|---|---|
| 1 | Center-align text | **Left-align and design for the Z-pattern**: top-left (kicker) → top-right (small marker) → big headline → supporting line → bottom-right (swipe / next step). Hierarchy: headline first, then subline, then small text. |
| 2 | Use old IG sizes (1080x1080, 1080x1350) | **Use the 2026 size: 1080 x 1440** (3:4). |
| 3 | Overload with graphics (doodles, stickers, sparkles, palettes everywhere) | **Keep it minimal**: one bold idea, lots of space, at most one strong visual element per slide. |
| 4 | Throw slides together randomly | **Fixed order: Hook → Point 1 → Point 2 → Point 3 → CTA** (5 slides). |
| 5 | Only make content that chases views (how-tos, tutorials, yap) | **Make content that gets buyers**: every carousel mixes **Personality, Value, Proof and a CTA**. |
| 6 | Use basic AI/Canva templates | **Stick to brand colours** and our own layout: Linen #F6F3E8, Deep Indigo #004EBA, Lime #7ED116, Sky #7DD2FD, Coral #EC464D (sparingly), Earth #844947, Ink #0B1B2B. |

Plus (Sheetal, 2026-10-10): **every carousel gets suitable music.** The Instagram API can't attach
Instagram's music library, so slides are published as short video slides that carry our own
royalty-free track (continuous across slides).

## Quick checklist
- [ ] 5 slides, Hook / Point 1 / Point 2 / Point 3 / CTA
- [ ] 1080x1440, left-aligned, Z-pattern hierarchy on every slide
- [ ] Minimal: no doodles, no emoji stickers, no clutter
- [ ] Brand colours only
- [ ] Personality line + value + a sourced proof point + CTA
- [ ] Music track attached
- [ ] Instagram rules still apply (no crypto vocabulary, honest risk line, disclaimer): `brand/instagram-strategy.md`
