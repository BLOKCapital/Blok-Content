# Trend boards

One file per day, `YYYY-MM-DD.md`, written by the morning trend check (Idea Deck refresh routine, 04:43 UTC) or by
whoever makes a post. Process and rules: `growth/trend-playbook.md`. The live copies sit in the shared folder at
`/mnt/project-files/growth/trends/`; commit the ones worth keeping.

`inbox/`: drop screenshots or links of formats, memes, Reels or audio you saw blowing up. The morning check reads
it, uses what fits, and moves used items to `inbox/used/`.

## Board template

```markdown
# Trend board YYYY-MM-DD (radar run HH:MM UTC)

## Top trends

|---|---|---|---|---|---|---|---|---|

- …

## Ready drafts
### 1. <platform, format>: <working title>
- Trend: <link>, Remix: <move>, Temp: mild / spicy / hot
- Source to cite: <primary source link> (verify before posting)

  …

## Inbox items used
- …
```
