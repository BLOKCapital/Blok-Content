# Content

| Folder | What goes here | Skill |
|---|---|---|
| `carousels/` | One folder per carousel: `slides.json`, `caption.md`, `export/` PNGs | `instagram-carousel` |
| `ugc-videos/` | One folder per video: `brief.md` (from `templates/ugc-brief.md`), `captions.srt`, assets | `ugc-video` |
| `short-form/` | Faceless/explainer Reels, TikToks, Shorts: storyboard, VO, SRT | `short-form-video` |
| `x-threads/` | `YYYY-MM-DD-slug.md` posts and threads | `x-thread` |
| `long-form/` | Blog posts, newsletters, Mirror/Paragraph articles | `blok-brand` |
| `calendar/` | `calendar.md` plan, `published.md` log, `learnings.md` | `content-ideation`, `composio-publish` |

Naming: `YYYY-MM-DD-short-slug`. Large raw video files don't belong in git; link to Drive/Dropbox in the brief.
