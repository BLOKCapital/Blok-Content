# Plain-English Glossary (for content)

Technical glossary: docs.blokcapital.io/en/concepts/glossary/glossary

| Term | Say it like this |
|---|---|
| **Garden** | Your own on-chain portfolio. It lives in your wallet, not ours. |
| **Garden Owner** | You. The person who planted the Garden and controls it. |
| **Index** | A ready-made basket of crypto with set weights, like an S&P 500 for crypto. |
| **Index Garden** | A Garden that follows an Index and rebalances itself. |
| **Self-managed Garden** | A Garden where you pick the assets and make the moves. |
| **Rebalancing** | Trimming what grew too big and topping up what shrank, to stay on target. (Pruning.) |
| **Market-cap weighted** | Bigger coins get a bigger slice, like most stock indices. |
| **Gardener** | A verified manager who can trade inside your Garden but can never take money out. (Coming soon.) |
| **Self-custody / non-custodial** | You hold the keys. Nobody else can move your money. |
| **Smart wallet (SWA)** | A wallet you open with Google sign-in. No 24-word seed phrase to lose. |
| **Account abstraction (ERC-4337)** | The tech that makes smart wallets and gasless transactions possible. |
| **Gasless** | You don't pay network fees for transactions. |
| **Soulbound token / pass (SBT)** | A badge that's stuck to your wallet and can't be sold or transferred. |
| **DAO** | The community runs it: token holders vote on changes. |
| **$BLOKC** | BLOK Capital's governance and rewards token on Arbitrum. |
| **Arbitrum** | A fast, cheap network built on top of Ethereum. |
| **Diamond (EIP-2535)** | A modular smart-contract design: one address, swappable "facets" of logic. |
| **Oracle (Chainlink)** | A trusted price feed so the protocol knows what assets are worth. |
| **On-chain** | Recorded on a public blockchain: anyone can verify it. |
| **DeFi** | Financial apps that run on smart contracts instead of banks. |
